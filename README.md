# 📡 Indosat Ooredoo Telecom Analytics

## Project Overview
Analisis traffic internet Milan (Nov 2013) untuk rekomendasi bisnis Indosat Ooredoo.

## Key Results
- **7.2M records** processed from 30 days of real data
- **10,000 grid cells** clustered into business vs entertainment zones
- **Forecast accuracy** of 89.2% (Prophet, MAPE 10.8%)
- **Peak hours:** 11:00-18:00 | **Low hours:** 02:00-05:00
